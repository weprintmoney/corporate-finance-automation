# Lesson 21 — Alternative Approaches

## Overview

If debt both adds value (by proving to be a tax benefit) and can destroy value (by increasing bankruptcy risk), we should be able to assess its effect on value separately by estimating the net value change from the debt. By the end of this lesson, students will be able to:

**Learning objectives:**
- Use the adjusted present value approach to estimate the effect of debt on firm value.

## Project Questions

- What is the expected tax benefit from borrowing money in the APV approach?
- What is the bankruptcy cost as a percent of value at your firm? (If you can estimate it)
- What is the optimal debt ratio using the APV approach?
- If it is different from the optimal using the cost of capital approach, how would you explain the difference?
