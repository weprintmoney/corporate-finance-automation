Source: https://pages.stern.nyu.edu/~adamodar/pc/datasets/finflowsRest.xls

Sheets: Variables & FAQ, Industry Averages

## Variables & FAQ

| End Game | To estimate the sustainable growth rate in earnings per share for a firm, if margins and ROE are stable. If margins are changing, these fundamental growth rates don't apply. |
|---|---|
|  |  |
| Variable | Explanation |
| Number of firms | Number of firms in the indusry grouping. |
| Dividends in $ millions | Aggregated dividends (regular and special) , across all firms in group, using trailing 12 month data. |
| Buybacks in $ millions | Aggregated stock buybacks, across all firms in group, using trailing 12 month data. |
| Equity Issuance in $ millions | Aggregated stock issuances, across all firms in group, using trailing 12 month data. |
| Net Equity Change in $ millions | Stock Issuances - Buybacks - Dividends |
| Net Equity Change as % of Book Equity | Net Equity Change/ Book Value of Equity |
| Debt Repaid in $ millions | Aggregated debt repayments, across all firms in group, using trailing 12 month data. |
| Debt Raised in $ millions | Aggregated new debt raiserd, across all firms in group, using trailing 12 month data. |
| Net Change in Debt in $ millions | Debt issues - Debt repaid |
| Net Change in Debt as % of Total Debt | (Debt issues - Debt repaid)/ Total Debt |
| Change in Lease Debt | Change in debt equivalent leases, as computed by accountants, over the last year. |
