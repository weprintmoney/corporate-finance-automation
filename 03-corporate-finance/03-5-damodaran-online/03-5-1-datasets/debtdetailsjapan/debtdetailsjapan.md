# Debtdetailsjapan

Source: https://pages.stern.nyu.edu/~adamodar/pc/datasets/debtdetailsJapan.xls

Sheets: Variables & FAQ, Indfustry Averages

## Variables & FAQ

| End Game | Details of debt held by firms (lease vs conventional, ST vs LT) |
|---|---|
|  |  |
| Variable | Explanation |
| Number of firms | Number of firms in the indusry grouping. |
| Lease Debt (my estimate) | Aggregated value of present value of lease commitments reported in financial statements, using the pre-tax cost of debt (my estimate) as the discount rate. (Lease commitments beyond year 5 converted into annual lease payments for extended period). |
| Conventional Debt | Aggregated value of all interest bearing debt, reported on balance sheet, including short term borrowings and long term borrowings. |
| Total Debt with leases | Sum of lease debt (my estimate) and conventional debt. |
| Interest Expense | Aggregated value of interest expenses of all firms in industry group, as reported in income statements.  |
| Book Interest rate | Aggregated value of interest expenses/ Aggregated value of conventional (interest-bearing) debt. |
| Short term Debt as % of Total Debt | Aggregated Short term (<1 year) debt as percent of aggregated conventional (interest-bearning) debt. |
| Lease Debt (Accounting) | Starting in 2019, IFRS and GAAP are requiring that lease commitments be reported as debt. Since the accounting rules for what should be counted as lease commitments and the discount rate used to get present value are different from mine, this number can be different from my estimate. |
