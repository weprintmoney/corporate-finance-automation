## Debt Ratio Regression: January 2015

**---**

**Variables used in the regression**

1. Debt
   Ratio = Debt/ (Market Value of Equity + Debt): If you can get market value
   of debt, use it. Else, use book value of debt.
2. Pre-tax ROC = EBIT/ (Book Debt + Book Equity - Cash)
3. Expected growth rate in revenues - next 2 years= You can use expected or even historical earnings growth, if you don't have a revenue growth forecast
4. EBITDA/
   Enterprise Value = EBITDA/ (Market Value of Equity + Book value of Debt - Cash)

* ***How do I use this regression?***

Assume that
you want to estimate the market debt ratio for a firm with the following
characteristics, using the US regression

EBITDA/
Enterprise Value = 8%

Pre-tax return on capital = 20%

Expected growth rate in revenues = 15%

* ***Predicted Value***

Expected
Debt Ratio= .236 -.023 (.15) + .548 (.08) -0.367 (.20) = .203 or 20.30%

If your
predicted value is less than zero, your predicted debt ratio is zero.
