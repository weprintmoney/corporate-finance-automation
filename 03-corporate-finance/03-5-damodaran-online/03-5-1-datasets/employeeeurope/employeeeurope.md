# Employeeeurope

Source: https://pages.stern.nyu.edu/~adamodar/pc/datasets/EmployeeEurope.xls

Sheets: Variables & FAQ, Industry Averages

## Variables & FAQ

| End Game | To evaluate how much value and revenue is created by an employee. |
|---|---|
|  |  |
| Variable | Explanation |
| Number of firms | Number of firms in the indusry grouping. |
| Number of Employees  | Total number of employees for the firm, at least as reported to the data services. |
| Market Cap/Employee | Aggregated market cap of firms that report employee count in sector/ Aggregated employee count |
| Revenue/Employee | Aggregated revenues of firms that report employee count in sector/ Aggregated employee count |
| Stock-based Compensation | Aggregated stock-based compensation (options and restricted stock) for companies in the sector. This is required under US GAAP but is less enforced in other parts of the world. So, a zero under stock-based compensation can either mean no equity compensation or that it was not reported as such. |
| Stock-based Compensation as percent of revenue | Aggregated stock-based compensation (options and restricted stock) for companies in the sector, divided by aggregated revenues across these companies.  |
|  |  |
| Calculation note: | Only a subset of companies (<20%) reports employee count. For the employee count numbers, we look at the revenues and market capitalization of only those companies. |
