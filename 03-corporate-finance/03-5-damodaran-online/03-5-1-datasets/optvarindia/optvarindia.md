# Optvarindia

Source: https://pages.stern.nyu.edu/~adamodar/pc/datasets/optvarIndia.xls

Sheets: Variables & FAQ, Industry Averages

## Variables & FAQ

| End Game | To estimate annualized standard deviation in equity and firm values |
|---|---|
|  |  |
| Variable | Explanation |
| Number of firms | Number of firms in the industry grouping. |
| Std Deviation in Equity | Average of annualized standard deviation in stock prices, across companies in group. |
| Std Deviation in Firm Value | Average of annualized standard deviation in firm value, across companies in group. |
| E/(D+E) | Aggregate market capitalization divided by aggregate firm value (market cap + total debt), across companies in group. |
| E/(D+E) | Aggregate total debt divided by aggregate firm value (market cap + total debt), across companies in group. |
