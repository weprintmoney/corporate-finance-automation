# What goes into debt?

| Category                                    | Calculation notes                                                                                                                                                                                            |
|---------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Interest bearing debt                       | If you can estimate market value of debt, do it. If not, use book value of debt and hope and pray that the firm is not distressed.                                                                           |
| Lease/Contractual Commitments               | Take the present value of lease and other contractual commitments, using the pre-tax cost of debt as your discount rate. (If you have capital leases, they should already be in your interest bearing debt). |
| Underfunded Pension/Health care obligations | If these are going to require "legally obligated" payments (to make the under funding go away), treat those payments like lease commitments and convert to debt.                                             |

# Consistency in MulPples

| <i>If value estimate is</i>                        | <i>Earnings divisors</i>                                                            | <i>Book value divisors</i>                                                                                                                         | <i>Revenue divisors</i>                                                       |
|----------------------------------------------------|-------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------|
| Market value of equity<br>(Market cap or variants) | Net Income (PE)                                                                     | Book value of common equity<br>(PBV)                                                                                                               | No consistent version (Do not<br>use)                                         |
| Firm Value                                         | EBIT + Income from cash &<br>cross<br>EBITDA + Income from cash<br>& cross holdings | Book value of common equity<br>+ Book value of preferred<br>stock + Book value of debt<br>(Firm value/ Book value)                                 | No consistent version (Do not<br>use)                                         |
| Enterprise value (without<br>leases)               | EBIT (EV/EBIT)<br>EBITDA (EV/EBITDA)                                                | Book value of invested capital<br>= Book value of debt + Book<br>value of equity - Cash - Book<br>value of cross holdings<br>(EV/Invested Capital) | Revenues (EV/Sales)<br>Subscribers/Members<br>(EV/Subscriber or<br>EV/Member) |
| Enterprise value (with leases<br>treated as debt)  | EBITDAR = EBITDA + Current<br>year's lease/rent expense<br>(EV/EBITDAR)             | Book value of invested capital<br>+ PV of lease commitments                                                                                        | Revenues (EV/Sales)<br>Subscribers/Members<br>(EV/Subscriber or<br>EV/Member) |
