## **Problem 4**

Current Beta = 1.20

|                 | <b>Assets</b> |     | <b>Liabilities</b>               |     |
|-----------------|---------------|-----|----------------------------------|-----|
| Assets          |               | 100 | Equity                           | 100 |
|                 |               |     |                                  |     |
| Helplessed Date |               |     | 1 - 20 U There is no date to see |     |

Unlevered Beta = 1.20 ! There is no debt

*After the transaction,*

| Assets |        | 100 | Debt   |             | 40 |
|--------|--------|-----|--------|-------------|----|
|        |        |     | Equity |             | 60 |
|        | Assets |     |        | Liabilities |    |

New Beta = 1.20 (1 + (1-0.4)(0.67)) = 1.68
