# Indregemerg24

Source: https://pages.stern.nyu.edu/~adamodar/pc/archives/indregemerg24.xls

Sheets: Variables & FAQ, Industry Averages

## Variables & FAQ

| End Game | To use historical return regresssions (against market index) to estimate risk paramters and measures of excess returns. |
|---|---|
|  |  |
| Variable | Explanation |
| Number of firms | Number of firms in the industry grouping. |
| Annualized Jensen's Alpha (Last 5 years) | Average of Jensen's alpha across firms in the grouping, where Jensen's alpha is computed as follows = Average annual return on stock over last 5 years minus Beta * Average annual return for the market over the last 5 years. |
| Beta | Simple average across firms of each firm's  beta, taken as a weighted average of 2-year and 5-year weekly return regression betas, with 2-year betas weighted 2/3rds. If the company has only a 2-year beta, it is used. |
| Correlation with the market | Average, across companies in the group, of correlation of stock with the market. |
