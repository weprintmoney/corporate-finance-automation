Sheets: Variables & FAQ, Industry Averages

## Variables & FAQ

| End Game | To estimate ratios of market values (equity and firm) to book value (equity and firm), with companion variables (ROE and ROC) |
|---|---|
|  |  |
| Variable | Explanation |
| Number of firms | Number of firms in the industry grouping. |
| ROE (unadjusted) | Aggregated net income divided by aggregated book value of equity, across all firms in the group. |
| ROE (adjusted for R&D) | Aggregate net income, adjusted for R&D, divided by aggregated book value of equity, adjusted for capitalized R&D, across companies in group. |
