## Variables & FAQ

| End Game | To measure the market value of the operating assets of firms, relative to operating fundamentals. |
|---|---|
|  |  |
| Variable | Explanation |
| Number of firms | Number of firms in the indusry grouping. |
| EV/EBITDAR&D | Aggregate enterprise value divided by aggregate earnings before interest, taxes, depreciation and R&D, across all firms in group. (Enterprise Value = Market Capitalization + Total Debt - Cash) |
| EV/EBITDA | Aggregate enterprise value divided by aggregate earnings before interest, taxes and depreciation, across all firms in group. (Enterprise Value = Market Capitalization + Total Debt - Cash) |
| EV/EBIT | Aggregate enterprise value divided by aggregate earnings before interest and taxes, across all firms in group. (Enterprise Value = Market Capitalization + Total Debt - Cash) |
| EV/EBIT (1-t) | Aggregate enterprise value divided by aggregate earnings before interest, but after taxes, across all firms in group. (Enterprise Value = Market Capitalization + Total Debt - Cash) |
