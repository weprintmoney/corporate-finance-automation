# Dollaremerg23

Source: https://pages.stern.nyu.edu/~adamodar/pc/archives/Dollaremerg23.xls

Sheets: Variables & FAQ, Industry Averages

## Variables & FAQ

| End Game | To report aggregated dollar value of key operating and marker numbers, by industry group, in millions of US $. |
|---|---|
|  |  |
| Variable | Explanation |
| Number of firms | Number of firms in the industry grouping. |
| Market Cap | Aggregated value of market capitalization of all companies in group. |
| Book Equity | Aggregated value of shareholders' equity  (book value of equity) of all companies in group. |
| Enterprise Value | Aggregated enteprise values of all companies in group. Enterprise Value = Market Cap + Total Debt - Cash. |
| Invested Capital | Aggregated capital invested in all companies in group. Invested Capital = Book Equity + Total Debt - Cash. |
| Total Debt | Total debt aggregated across all firms in group, based upon last balance sheet |
| Revenues | Aggregated value of revenues across all companies in the group. |
| Gross Profit | Aggregated value of gross profits across all companies in the group. |
| EBITDA | Aggregated value of earnings before interest, taxes and depreciation (EBITDA) across all companies in the group. |
| EBIT (Operating Income) | Aggregated value of operating profits across all companies in the group. |
| Net Income | Aggregated value of net income across all companies in the group. |
