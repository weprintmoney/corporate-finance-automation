| Part d |
| The source of the problem (as you undoubtedly noticed) is that the market value of equity in the cost |
| of capital calculation does not match the estimated value of equity. If you want convergence, you have to replace |
| the market value of equity in the cost of capital calculation with the estimated value of equity to compute the weights. |
|  |
| In the real world, this happens almost every single time. Consider how we compute cost of capital (in both corporate finance |
| and valuation). We use the market values of debt and equity to weight them in coming up with a cost of capital. We then use the |
| cost of capital to come up with new (and different) values at least for equity. Consequently, the equity value that we obtain in |
| conventional firm valuation will never match the equity value from a pure equity valuation. |
|  |
| Does this mean that you should not use existing market values of equity and debt in computing cost of capital? Not necessarily. |
| The reason we use the existing market values to come up with weights is that we have to pay whatever the prevailing market |
| price is buy a company's stock and not our estimate of it's value… Hence, I guess we have to learn to live with the inconsistency |
| created by differences between market perceptions of value and our own perceptions of the same. |
|  |
| Part e |

| but you also have to ensure that the debt ratio that you use in the equity valuation is consistent with the debt ratio you used in the cost of capital. |
