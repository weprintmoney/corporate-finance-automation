# Modules

Applied Corporate Finance course content — 36 lessons across 4 modules.

| File | Description |

## Navigation

To find a specific lesson, read `lesson-index.yaml` — it lists every lesson's folder and what file types are present (slides, transcripts, spreadsheets, readings, blogs). Jump directly to the lesson folder rather than scanning module sub-folders.

## Key rule — video files

`.mp4` files are binary video recordings stored via Git LFS. **Never read them.** The transcript `.md` with the same filename stem is always present alongside the `.mp4` and contains the full lecture text.
