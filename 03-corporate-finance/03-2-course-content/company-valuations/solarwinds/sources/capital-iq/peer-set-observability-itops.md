## Caveats

- Debt weights here use CIQ's total debt, which includes lease liabilities for some peers.
- CIQ did not show betas or tax rates on these pages. Use Damodaran's industry betas already in `../market-data/` for unlevering.
- Rapid7 and PagerDuty carry convertible debt, so their debt weights overstate straight-debt leverage.
- Adding peers to the Quick Comps grid through the lookup widget did not work in this account, so the figures above come from each company's own pages.
