| PRELIMINARY STUFF AND INPUTS                       | nan                                                                                            |
| Objective                                          | This spreadsheet allows you to compute the optimal capital structure for a non-financial       |
| nan                                                | service firm                                                                                   |
| Before you start                                   | Open preferences in excel, go into calculation options and put a check in the iteration box.   |
| nan                                                | If it is already checked, leave it as is.                                                      |
| Inputs                                             | The inputs are primarily in the input sheet. If your company has operating leases,             |
| nan                                                | use the operating lease worksheet to enter your lease or rental commitments.                   |
| Units                                              | Enter all numbers in the same units (000s, millions or even billions)                          |
| Income inputs                                      | The key income input is the earnings before long term interest expenses and depreciation.      |
| nan                                                | Enter the most updated numbers you have for each (even if they are 12-month trailing           |
| nan                                                | numbers). If the most recent period for which you have data has an operating income that       |
| nan                                                | is abnormal, either because of extraordinary losses/gains or some other occurrence, use        |
| nan                                                | an average operating income over the last few years.                                           |
| Balance Sheet                                      | Enter the book value of total debt. If you have a market value enter that                      |
| nan                                                | number. Alternatively, input the average maturity of the debt and I will estimate the          |
| nan                                                | market value of debt.                                                                          |
| Market Data                                        | Enter the current stock price, the current risk free rate, the equity  risk                    |
| nan                                                | premium you would like to use to estimate your cost of equity and the current rating for       |
| nan                                                | your firm. If you do not have a rating, there is an option for you at the very bottom of       |
| nan                                                | the spreadsheet to compute a synthetic rating.                                                 |
| Tax Rate                                           | Enter a marginal tax rate, if you can find it. Otherwise, use the marginal tax rate of country |
| Default Spreads                                    | This spreadsheet has interest coverage ratios, ratings and default spreads built into it in    |
| nan                                                | the worksheet. You can choose between two tables, one for large and stable                     |
| nan                                                | firms, and the other for small or risky firms. If you want you can change the interest         |
| nan                                                | coverage ratios and ratings in these tables.                                                   |
| READING THE OUTPUT                                 | nan                                                                                            |
| Summary                                            | The summary provides a picture of your firm's current cost of capital and debt ratio, and      |
| nan                                                | compares it to your firm's optimal debt ratio and the cost of capital at that level. The       |
| nan                                                | firm value is computed at each debt ratio, based upon how the expected operating income        |
| nan                                                | and the cost of capital. The optimal debt ratio is that ratio at which firm value is           |
| nan                                                | maximized. It might not be the same point at which cost of capital is minimized.               |
| Details                                            | The details of the calculation at each debt ratio are below the summary.                       |
| References                                         | nan                                                                                            |
| Corporate Finance: Theory and Practice, Chapter 18 | nan                                                                                            |
| Applied Corporate Finance: Chapter 8               | nan                                                                                            |
