# Lesson 34 — Value of Control

## Overview

The value of control reflects your belief that you can run a company better than the existing management, and that with the changes that you would put into the company, it would have a higher value than it does under the existing management. By the end of this lesson, students will be able to:

**Learning objectives:**
- Value control, by valuing a company twice, once with the status quo (existing management) and once with superior management, and then multiplying the difference in values (between the status quo and superior management) by the probability of management change.

## Project Questions

- What is the status quo value of your firm?
- If you were running this firm, what would you change about the way the firm is run (in terms of investing, financing and dividend decisions)?
- What is the value of your firm with these changes made?
- What is the likelihood that this change will happen?
