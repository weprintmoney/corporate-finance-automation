# Corporate Finance Automation

Personal coursework repo — Financial Accounting, Statistics, Corporate Finance, and the Final Project.

Structured as a "Team OS"-style knowledge base so an AI session opened in any subfolder already knows the subject, the conventions, and where things live. See [`CLAUDE.md`](CLAUDE.md) for the map.

## Structure

- `financial-accounting/` — accounting foundations, statements, ratios
- `statistics/` — distributions, tests, regression
- `corporate-finance/` — TVM, valuation, WACC, capital budgeting
- `final-project/` — capstone

## Solo repo

Sole contributor. No PR approvals required, but direct push to `main` is blocked — branch, open a PR, self-merge.
